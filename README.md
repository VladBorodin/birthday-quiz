# Birthday Quiz — структура v2

Это второй, более узкий этап разработки. Игровой контент пока намеренно не реализован.

## Что изменено

### 1. Команды
- 4 команды по умолчанию: Марина, Татьяна, Слава, Стас.
- Названия редактируются.
- Счёт редактируется вручную.
- Быстрые `-1` и `+1`.
- Выбор активной команды.
- Можно добавлять и удалять команды.

### 2. Переключения
Системные экраны доступны всегда:
- Заставка
- Табло
- Таймер
- Пауза

Ниже три вкладки:
- Игра 1
- Игра 2
- Игра 3

У каждой игры есть список разделов/раундов. Раздел раскрывается и показывает готовые заголовки сцен.

Пока это тестовые заголовки. Они задаются централизованно в:

`data/structure.js`

Именно этот файл позже будет расширяться реальными играми и их сценами.

### 3. Базовое управление
Всегда видно:
- текущую игру / системный экран;
- текущий раунд;
- текущую сцену;
- Назад / Далее;
- управление таймером;
- вывод большого таймера на экран;
- включение/отключение сигнала окончания.

### 4. Трансляция
В админке встроен `iframe` с `screen.html`.

Это тот же экран, который открывается на втором мониторе, поэтому превью не является отдельной копией интерфейса.

### Экран зрителей
- сверху постоянное табло команд;
- в центре текущая системная или игровая сцена;
- снизу постоянная визуальная шкала таймера;
- системное «Табло» показывает крупный рейтинг;
- системный «Таймер» показывает крупный таймер.

## Запуск

Запустить `start.bat`.

Откроются:
- `admin.html`
- `screen.html`

Экран зрителей переносится на второй монитор и разворачивается на весь экран.
